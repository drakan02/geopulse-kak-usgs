# Báo cáo phát sinh tại máy

inspect, verify, test và benchmark xuất JSON vào đây. File phát sinh được Git
ignore để không ghi đè số đo của thành viên khác khi commit. Bằng chứng đã chọn
cho lần bàn giao nằm ở [evidence](../evidence/README.md) và được commit riêng.

Đọc CV2_REPORT.md để biết môi trường, phương pháp và giới hạn. Chỉ dùng kết quả
benchmark trên database thật; không suy thời gian truy vấn từ kiểm tra cú pháp.
